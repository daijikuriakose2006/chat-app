# Firebase Firestore Database Schema & Free-Tier Setup

This app connects to **Cloud Firestore**, a NoSQL document database. Firestore is completely free to use within Firebase's Spark Plan (free tier) and does not require setting up a billing account or credit card.

---

## ⚠️ IMPORTANT: How to Bypass Billing Prompts (Free Setup)

If Firebase is asking you to add billing/payment information, it is usually due to one of three reasons:

### 1. Creating a Named (Secondary) Database
In the free tier, Firebase allows exactly **one** free database per project, which **must** be named **`(default)`**.
* **Fix**: When you click **Create Database** in the console, make sure the database ID is set to `(default)`. If you type a custom name (e.g. `chatapp-db`), Firebase will classify it as a secondary database and prompt you to upgrade to the Blaze plan (requiring billing).

### 2. Accidental Upgrades / Active Services
If you previously initialized **Firebase Data Connect**, **Cloud Functions**, or **Cloud SQL** (PostgreSQL) in this project, Firebase automatically prompts you to upgrade to the Blaze plan because those specific services require a paid tier.
* **Fix**: The easiest solution is to **create a new Firebase Project** (e.g., `chatapp-free-version`) which starts clean on the free Spark plan, and only enable **Authentication** and **Firestore** on it. Do not initialize Data Connect or Functions.

### 3. Creating Firestore from Google Cloud Console
If you navigate to the Google Cloud Console (`console.cloud.google.com`) to create Firestore, it will force you to set up billing.
* **Fix**: Only create the database directly inside the [Firebase Console](https://console.firebase.google.com/).

## 2. How Firestore Collections Work (NoSQL)
Unlike SQL or Firebase Data Connect, you do **not** need to create tables or define schemas beforehand. Firestore creates collections and documents automatically as soon as the app writes data to them.

Here is how the data structures map in Firestore:

### `users` Collection
- **Path**: `/users/{uid}` (Document ID matches the user's Auth UID)
- **Document Fields**:
  - `uid`: `String` (e.g. `"u8Yd921Lz..."`)
  - `displayName`: `String` (e.g. `"Ada Lovelace"`)
  - `email`: `String` (e.g. `"ada@example.com"`)
  - `photoURL`: `String` (Avatar image URL)
  - `status`: `String` (`"online"` or `"offline"`)
  - `lastSeen`: `Timestamp` (Server timestamp of last action)

### `rooms` Collection
- **Path**: `/rooms/{roomId}` (Document ID is auto-generated by Firestore)
- **Document Fields**:
  - `id`: `String` (Matches the Document ID)
  - `name`: `String` (Unique name of the room)
  - `visibility`: `String` (`"public"` or `"private"`)
  - `password`: `String` (Password string, present if visibility is private)
  - `createdBy`: `String` (UID of the creator user)
  - `createdAt`: `Timestamp`
  - `lastMessage`: `String` (Preview text of the latest message)
  - `lastMsgTime`: `String` (Formatted string of the latest message time, e.g. `"10:30 PM"`)

### `messages` Subcollection
- **Path**: `/rooms/{roomId}/messages/{messageId}` (Subcollection inside each room)
- **Document Fields**:
  - `text`: `String`
  - `senderId`: `String` (UID of the sender)
  - `senderName`: `String` (Denormalized displayName)
  - `senderPhoto`: `String` (Denormalized photoURL)
  - `createdAt`: `Timestamp`

### `typing` Subcollection (Typing Indicators)
- **Path**: `/rooms/{roomId}/typing/{userId}` (Temporary indicator documents)
- **Document Fields**:
  - `displayName`: `String`
  - `typedAt`: `Timestamp`

## 3. How to Create the Database for Free (Firebase Console)

### Step 1: Open the Firebase Console
1. Go to the [Firebase Console](https://console.firebase.google.com/).
2. Select your project.

### Step 2: Create Firestore Database
1. In the left navigation panel, click on **Build** -> **Firestore Database**.
2. Click the **Create database** button.
3. **Important**: Choose **`(default)`** as the database ID.
4. Select a location closest to you.
5. Choose **Start in test mode** so your app can read and write right away.
6. Click **Create**.
